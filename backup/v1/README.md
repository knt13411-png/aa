# 사후검토 분석기 (MVP v1.0)

훈련 데이터 엑셀을 올리면 결과 그래프, 6대 기능 원인 진단, 훈련 간 비교를 바로 보여 주는 **단일 HTML 도구**입니다. 설치와 네트워크가 필요 없습니다.

## 실행
- `dist/사후검토_분석기.html`을 Chrome 또는 Edge(최신)에서 더블클릭해 엽니다.
- 처음 실행하면 [기록 목록 › 저장 폴더 지정]에서 공유 폴더(예: `AAR_데이터`)를 한 번 지정합니다. (저장 방식 A)
- 폴더 저장을 지원하지 않는 브라우저에서는 자동으로 브라우저 저장(방식 B)으로 바뀝니다. 다른 PC로 옮길 때는 목록의 [내보내기]로 만든 .zip을 [훈련 불러오기]로 가져옵니다.

## 사용 순서
1. **새 훈련**: 엑셀을 끌어 놓고 훈련명을 입력한 뒤 [분석]을 누릅니다. 오류 행이 있으면 행 번호가 표시되고, 오류 행을 빼고 진행할 수 있습니다.
2. **분석 대시보드**
   - ① 결과 분석: 교전 현황, 명중률, 피해/생존, 시간대별 추이, 화기별, 제대별 비교. 막대를 누르면 하위 제대로 내려가고, 상단 경로를 누르면 위로 올라갑니다.
   - ② 6대 기능 진단: 레이더 차트, 기능별 지표와 판정, 진단 문장, 담당자 소견 입력
   - ③ 훈련 비교: 저장된 훈련 2~5건을 같은 제대 수준에서 비교합니다.
3. **저장**: 소견을 입력한 뒤 [저장]을 누릅니다.
4. **출력**: 그래프마다 [PNG] 버튼이 있고, [화면 전체 PNG]는 현재 탭 전체를 1920×1080 한 장으로 저장합니다. [전체화면]은 회의 모드로, ←/→ 키로 그래프를 넘기고 Esc로 끝냅니다.

## 저장 구조
```
AAR_데이터/2026-10_백두3호훈련/
  _훈련정보.json   _분석_전체.json   _소견.json(훈련 전체)
  _원천/원천데이터.xlsx
  1여단/_분석.json, _소견.json
    1대대/…/1중대/…/1소대/…
```

## 진단 규칙 (설정에서 수정 가능)
- 비교 기준: **시작일이 더 이른 저장된 훈련들**에서 같은 진영·같은 제대 수준(예: 훈련부대 대대) 지표 평균
- 지표별 개선율이 +N% 이상이면 강점, −N% 이하이면 취약입니다. 기본 N은 15입니다.
- 기능 종합지수는 지표별 지수(이전 평균=100)의 평균입니다. 간접화력 피해 비율은 참고 지표라 판정에서 뺍니다.
- 이전 훈련이 없으면 "비교 기준 없음"으로 표시합니다.

PRD에 정의되지 않아 이번에 정한 계산 기준은 다음과 같습니다. 실제 양식을 확인한 뒤 바꿀 수 있습니다.

| 항목 | 기준 |
|---|---|
| 교전 수 | 소대(최하위 제대)별로 사격 간격이 5분을 넘으면 별개 교전으로 셈 |
| 인원 | 위치·피해·교전 기록에 나온 개체ID 수 |
| 생존율 | (인원 − 사망) ÷ 인원. 개체별로 가장 심한 피해 판정을 씀 |
| 명령 하달 / 보고 소요시간 | 응답시각 − 시각. 보고는 180초를 넘으면 지연 |
| 지휘통신 귀속 | 발신제대와 수신제대(상위 제대 포함) 모두에 귀속 |
| 선탐지 | 탐지시각 < 상대탐지시각, 또는 상대탐지시각이 비어 있음 |
| 초기 피해 집중도 | 제대의 첫 사격·첫 피해 중 이른 시각부터 30분 안에 난 피해 비율 |
| 탄약 보급률 | 탄약보급 수량 합 ÷ 탄약소모량 합 (소모량이 없으면 사격 수로 대신함) |

## 개발
- 소스: `src/` (app.html, app.css, js/*.js), 라이브러리: `lib/` (SheetJS 0.18.5, Chart.js 4.4.1)
- 빌드: `powershell -ExecutionPolicy Bypass -File tools\build.ps1` → `dist/사후검토_분석기.html`
- 가상 샘플: `powershell -ExecutionPolicy Bypass -File tools\make_samples.ps1` → `samples/` 3건 (모두 가상 데이터)
  - 1호: 기준 / 2호: 화력↑ 기동↓ / 3호: 지휘통제·정보·방호↑ 작전지속지원↓ (1여단 2대대는 숙련도를 낮게 설정)
- `tools/serve.ps1`은 개발 점검용 로컬 서버이며, 실사용에는 필요하지 않습니다.
