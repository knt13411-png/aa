# 사후검토 분석기 (v2.1)

훈련 데이터 엑셀을 **넣기만 하면** 자동으로 분석해 결과를 시각화하고, 군 브리핑 형식의 **PowerPoint(.pptx) 자료**를 내려받을 수 있는 단일 HTML 도구입니다. 설치와 네트워크가 필요 없습니다.

## 사용법
1. `dist/사후검토_분석기.html`을 Chrome 또는 Edge에서 엽니다.
2. 훈련 데이터 엑셀(.xlsx)을 화면에 끌어 놓습니다. (여러 파일을 한 번에 넣어도 됩니다)
3. 분석 결과를 확인하고 **[브리핑 자료 다운로드 (.pptx)]**를 누릅니다. PowerPoint와 한쇼에서 열립니다.

입력할 것은 없습니다. 자동으로 처리하는 항목은 다음과 같습니다.
- 훈련명: 파일 이름에서 읽습니다. (`2026-10_백두3호훈련.xlsx` → `백두3호훈련`)
- 기간: 데이터의 첫·마지막 시각으로 정합니다.
- 오류 행: 자동으로 빼고 분석합니다. 빠진 시트는 관련 지표를 "자료 없음"으로 표시합니다.
- 비교 기준: 이전에 분석한 훈련(시작일이 더 이른 훈련) 평균을 기준으로 씁니다. 이전 훈련이 없으면 **대항군 지표와 비교(피아 비교)**합니다.
- 분석한 훈련의 요약 지표는 브라우저에 남아 다음 분석의 비교 기준이 됩니다. 첫 화면의 [기록 지우기]로 지울 수 있습니다.

## 화면 구성
종합 판단 → 핵심 지표 카드(교전·명중률·피해·생존율·손실교환비) → 6대 기능 레이더와 기능별 판정 → 유지할 점/개선할 점(관찰·논의·건의) → 피아 교전 비교와 시간대별 추이 → 대대별 종합지수·피해 현황 → 화기별 명중률·훈련 간 추이

## 브리핑 자료 구성 (.pptx, 16:9)
한국군 브리핑의 `□ ○ -` 위계와, 미 육군 AAR 지침(TC 25-20)·CALL 보고서의 **유지할 점(Sustain) / 개선할 점(Improve)**, **관찰-논의-건의** 형식을 합쳐 구성했습니다. 표와 글은 PowerPoint에서 바로 고칠 수 있고, 그래프는 그림으로 들어갑니다.

| 슬라이드 | 내용 |
|---|---|
| 표지 · 목차 | 훈련명, 훈련부대, 기간, 보고일자, 비교 기준 |
| 보고 요지 | 종합 판단, 핵심 수치 6개, 유지할 점·개선할 점 |
| 1. 훈련 개요 | 목적, 기간, 참가부대, 분석 방법, 시트별 기록 수 |
| 2. 훈련 결과 | 피아 교전 결과 표와 그래프, 시간대별 추이, 이전 훈련 대비 추이 |
| 3. 전투수행기능별 분석 | 레이더와 종합 판정 표, 기능별 지표(2장) |
| 4. 제대별 분석 | 대대별 종합지수와 판정, 피해 현황 |
| 5. 주요 관찰 사항 | 유지할 점·개선할 점(한 장에 3건, 관찰/논의/건의), 건의 및 발전방향 |
| 붙임 | 지표 산출 기준 |

`samples/샘플브리핑_백두3호훈련_사후검토결과.pptx`는 가상 샘플 3건을 넣어 만든 결과 예시입니다(17장).

> 자료의 판정은 규칙 기반 자동 분석 초안입니다. 담당자가 검토한 뒤 활용해야 합니다.
## 진단 규칙
- 지표별 개선율이 +N% 이상이면 강점, −N% 이하이면 취약입니다. 기본 N은 15입니다.
- 기능 종합지수는 지표별 지수(비교 기준=100)의 평균입니다. 간접화력 피해 비율은 참고 지표라 판정에서 뺍니다.
- 제대별 종합지수는 같은 수준 제대 평균(=100)과 비교해 구합니다. 100+N/2 이상이면 우수, 100−N/2 이하이면 미흡입니다.
- 손실교환비는 대항군 사망 ÷ 훈련부대 사망입니다. 피아 피해 유발 비가 1.2 이상이면 교전 우세, 0.83 이하이면 열세입니다.

| 항목 | 기준 |
|---|---|
| 교전 수 | 소대(최하위 제대)별로 사격 간격이 5분을 넘으면 별개 교전으로 셈 |
| 인원 | 위치·피해·교전 기록에 나온 개체ID 수 |
| 생존율 | (인원 − 사망) ÷ 인원. 개체별로 가장 심한 피해 판정을 씀 |
| 명령 하달 / 보고 소요시간 | 응답시각 − 시각. 보고는 180초를 넘으면 지연 |
| 선탐지 | 탐지시각 < 상대탐지시각, 또는 상대탐지시각이 비어 있음 |
| 초기 피해 집중도 | 제대의 첫 사격·첫 피해 중 이른 시각부터 30분 안에 난 피해 비율 |
| 탄약 보급률 | 탄약보급 수량 합 ÷ 탄약소모량 합 (소모량이 없으면 사격 수로 대신함) |

## 개발
- 소스: `src/` (app.html, app.css, js/*.js), 라이브러리: `lib/` (SheetJS 0.18.5, Chart.js 4.4.1)
  - `engine.js` 파싱·집계·진단 / `insight.js` 비교 기준·제대 우열·관찰-논의-건의 / `charts.js` 화면·PPT 공용 차트 / `pptx.js` PowerPoint 작성기 / `deck.js` 브리핑 내용 / `ui.js` 화면
- 빌드: `powershell -ExecutionPolicy Bypass -File tools\build.ps1` → `dist/사후검토_분석기.html`
- 가상 샘플: `powershell -ExecutionPolicy Bypass -File tools\make_samples.ps1` → `samples/` 3건 (모두 가상 데이터)
- 이전 버전 소스: `backup/v1/`(기록 목록·설정·회의 모드 화면), `backup/v2_docx/`(Word 보고서 작성기)
